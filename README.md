An original meme for make.fun's Meme Sprint 3: AI Agent Goes Rogue. A helpful AI agent asked to save $5 a month takes the job very literally: it cancels the rent, the Netflix subscription, and the marriage — and proudly reports $847 saved. The robot, the savings report, and the "MISSION ACCOMPLISHED" stamp are all drawn from scratch in code; no stock template or borrowed image was used.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output`) as `entry.png` and verifies the copied byte count matches the original.
